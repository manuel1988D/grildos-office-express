# Grildos Office Express

Landing page profesional creada como prototipo funcional de modelo de negocio digital para Grildos Pastry & Bakery.

## Tecnologías usadas

- React
- Vite
- Tailwind CSS
- HTML semántico
- Diseño responsive
- Sin backend
- Lista para desplegar en Vercel

## Instalación local

```bash
npm install
npm run dev
